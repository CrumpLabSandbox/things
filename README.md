## Readme

Visual portfolio website for Matt Crump.

Built with Quarto.

## Data layer

Every piece in `images/` has a JSON record in `data/artworks/<series>/<slug>.json`
with catalog facts, measured colour and structure features, and a written
description with tags. `explore.qmd` browses them. See `PLAN.md` for the
scripts, the local editing tool and the build steps.
